# CP/M-80 2.2 for NEC PC-8001mkII

PC-8001mkII向けのCP/M-80 2.2起動用2D FDイメージです。DITT.EXEなどのツールでFDに書き込んで実機で利用したり、HxCやGotekのFDDエミュレータなどで利用できます。PC-80S31やその互換FDDがあることを前提に作成しています。開発と動作検証はロジテックのK-305PCで実施しました。

## 注意事項

画面出力とキーボードによる入力には対応していません。RS-232Cポートにシリアル端末を接続して利用してください。通信速度は9600bpsを想定しています。PC-8001mkII側は、背面のDIPスイッチで設定できます。

処理高速化のために、1トラック分のディスクキャッシュをFDD内のRAMに作成して利用しています。そのため、電源断によって、ファイルの変更内容が失われる恐れがあります。CP/Mのウォームブート時には強制的にキャッシュを書き戻すので、気になる人はウォームブートするSYNC.COMなどを作成してください。簡易的には、現在アクセス中ではない別のドライブをdirすることでもキャッシュを書き戻せます。

2Dディスク専用です。1Dディスクには対応していません。

## FDFORMAT.COM

フォーマット用のFDFORMAT.COMを同梱しています。

```
fdformat b:
```

のようにオプションなしで実行すると、CP/M用のデータディスクとしてディスクを初期化します。CP/Mを起動可能なディスクを作成する場合には、次のように /S オプションを指定してください。

```
fdformat /S b:
```

なお、/L オプションを指定すると低レベルフォーマットのみを実施します（FDDに05Hコマンドを発行するだけ）。

## 利用ライセンス

自作部分（ブートコードとBIOS）は、MITライセンスを採用しています。適当に改造して使ってください。CP/Mのライセンスについては、LICENSE.CPM を参照してください。

## diskdefs

cpmtoolsで利用可能なディスク定義ファイルです。cpmtoolsでCP/Mのイメージファイルを作成、操作する場合に利用します。

## 余談

PC-8001mkIIとK-305PCをネットオークションで落札したのですが、DOS（やDISK BASIC）が手軽に入手できそうにない状況と分かって、CP/MのBIOSを作ることにしました。この辺の機種はS-OSがあるから大丈夫さと下調べをしなかった報いですね。開発時に一番困ったのは、K-305PCが不調だったことです。ソフト起因かハード起因か切り分けできない謎のエラーに悩まされましたが、電解コンデンサを2つ交換したら、問題なく動くようになりました。

画面出力に対応していないのは、もちろんそれが手軽だったからですが、テキストVRAMが嫌な位置にあって切り離せない問題と、CRTCによる割り込みDMAによる速度低下問題をまとめて解消できる利点があるので、そのままにしています。
