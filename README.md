# CP/M-80 2.2 for NEC PC-8001mkII

PC-8001mkII向けのCP/M-80 2.2起動用2D FDイメージです。DITT.EXEなどのツールでFDに書き込んで実機で利用したり、HxCやGotekのFDDエミュレータなどで利用できます。PC-80S31やその互換FDDがあることを前提に作成しています。開発と動作検証はロジテックのK-305PCで実施しました。

64k CP/Mと59k CP/Mの2種類があります。

64k版はPC-8001mkIIのコンソール（画面出力とキーボード）には対応していません。RS-232Cポートにシリアル端末を接続して利用してください。通信速度は9600bpsを想定しています。PC-8001mkII側は、背面のDIPスイッチで設定できます。TPAが広いだけでなく、画面出力を無効化していることで59k版よりも高速に動作します。

59k版はPC-8001mkIIのコンソールを利用できます。ANSI/VT100のエスケープシーケンスの一部をサポートしていますが、カラー表示と文字装飾には対応していません。元々は対応させるつもりだったのですが、PC-8001mkIIのテキストVRAMの仕様を知って諦めました。「STAT CON:=TTY:」または「STAT CON:=UC1:」を実行すれば、シリアル端末を接続して使うことも可能です。

どちらも2Dディスク専用です。1Dディスクには対応していません。

## 利用上の注意

処理高速化のために、1トラック分のディスクキャッシュをFDD内のRAMに作成して利用しています。そのため、不用意な電源断やディスク交換でファイルの変更内容が失われる恐れがあります。電源を切ったりディスクを交換したりする際には、CCPのプロンプトでCtrl-Cを入力し、再度プロンプトが表示されるまで待つようにしてください（CP/Mのウォームブート時にキャッシュを書き戻します）。

## FDFORMAT.COM

フォーマット用のFDFORMAT.COMを同梱しています。

```
FDFORMAT B:
```

のようにオプションなしで実行すると、CP/M用のデータディスクとしてディスクを初期化します。CP/Mを起動可能なディスクを作成する場合には、次のように /S オプションを指定してください。

```
FDFORMAT /S B:
```

なお、/L オプションを指定すると低レベルフォーマットのみを実施します（FDDに05Hコマンドを発行するだけ）。

## diskdefs

cpmtoolsで利用可能なディスク定義ファイルです。cpmtoolsでCP/Mのイメージファイルを作成、操作する場合に利用します。

## 余談

PC-8001mkIIとK-305PCをネットオークションで落札したのですが、DOSの類（やDISK BASIC）が手軽に入手できそうにない状況と分かって、CP/MのBIOSを作ることにしました。この辺の機種はS-OSがあるから大丈夫さと下調べをしなかった報いですね。開発時に一番困ったのは、K-305PCが不調だったことです。ソフト起因かハード起因か切り分けできない謎のエラーに悩まされましたが、電解コンデンサを2つ交換したら、問題なく動くようになりました。

59k版のブートコードやBIOSはZ80向けのアセンブリ言語、64k版は8080向けのアセンブリ言語で記述しています。59k版の方はBIOSのコード量が増え、サイズを圧縮するためにZ80命令を使ったからです（59k版では、起動メッセージをブートコードに入れる工夫もしています）。59k版のソースコードはz80asm、64k版のソースコードはasm8080などを使ってアセンブルしてください。
